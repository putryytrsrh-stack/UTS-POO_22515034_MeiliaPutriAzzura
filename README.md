# Akademik Mini

Akademik Mini merupakan program sederhana berbasis Java yang dibuat untuk membantu proses pengelolaan data akademik mahasiswa dan mata kuliah.

Program ini dibuat sebagai tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Berorientasi Objek (OOP).

## Fitur Program
1. Menambahkan data mahasiswa.
2. Menampilkan data mahasiswa.
3. Menambahkan data mata kuliah.
4. Menampilkan data mata kuliah.
5. Membuat Kartu Rencana Studi (KRS).
6. Mencari data mahasiswa berdasarkan NIM.
7. Mengelola riwayat menggunakan struktur data Stack.
8. Menampilkan ringkasan data akademik.

## Penerapan OOP
Program ini menerapkan konsep:
- Class dan Object.
- Encapsulation.
- Constructor.
- Getter dan Setter.
- Relasi antarclass.

## Struktur Class
- Mahasiswa
- MataKuliah
- KRS
- Kampus
- StackRiwayat
- Main
